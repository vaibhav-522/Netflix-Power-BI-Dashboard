An interactive Power BI dashboard analysing **8,807 Netflix titles** by type, release decade, runtime, seasons, rating and year added.

   ![Dashboard Screenshot] <img width="1413" height="745" alt="Netflix_Dashboard_Overview" src="https://github.com/user-attachments/assets/af6553eb-d2bd-4f51-a082-dcc83b49417b" />

   
## 📌 Dashboard Contents
- **KPI cards:** Total Titles, Total Movies, Total TV Shows, Total Directors, Total Countries, YoY Growth %
- **Slicers:** Type, Release Decade, Date Added
- **Visuals:** Titles added per year (line), Movies vs TV Shows (donut), Titles by Rating (bar), Movies by Runtime Bucket (column), TV Shows by Number of Seasons (column)

## 🔍 Key Insights
- **8,807 titles** in total: **6,131 movies (70%)** and **2,676 TV shows (30%)**.
- Content additions **peaked in 2019** with 2,016 titles (1,424 movies and 592 TV shows).
- Additions fell **6.8% in 2020** and **20.3% in 2021**. The 2021 data ends on 25 Sep, so that drop is partly an incomplete year.
- **85% of titles** were released in 2010 or later. The 2010s alone account for 5,927 titles.
- Most movies run **90–120 minutes**, and the median runtime is about 98 minutes.
- **67% of TV shows** have only one season.
- **TV-MA (3,207)** and **TV-14 (2,160)** are the most common ratings, so the catalog skews toward mature and teen audiences.
